# Inventory-Management-System
1. Project Overview

The Inventory Management System is a full-stack web application designed to simplify and manage inventory-related operations. It enables users to manage vendor details, material categories, material information, and purchase entries through an interactive user interface.

The application follows a microservices architecture, with independent backend services communicating through RESTful APIs to ensure modularity and maintainability.

2. Key Features:

i) Vendor management

ii) Material category and type management

iii) Inventory and material details management

iv) Purchase entry and tracking

v) REST API integration between microservices

vi) React-based user interface

3. Technology Stack

i) Backend: Java, Spring Boot

ii) Frontend: React.js, JavaScript, HTML, CSS

iii) Database: MySQL

iv) Architecture: Microservices, RESTful APIs

v) Tools: Maven, Git, Jenkins, SonarQube, Postman

4. Project Structure

i) The application consists of three backend microservices:

ii) Vendor Service: Manages vendor-related information.

iii) Material Service: Handles material categories, types, and units.

iv) Inventory Management Service: Manages purchase and inventory operations and integrates with the Vendor and Material services.

5. Purpose:

The project demonstrates full-stack application development, microservices integration, REST API development, and database management using Java-based technologies.
